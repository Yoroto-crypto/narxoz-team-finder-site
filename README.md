# Narxoz Team Finder — сайт (без Telegram)

Публичная доска объявлений для поиска сокомандников: любой заходит по
ссылке, без входа/регистрации, видит все анкеты и может разместить свою.
Заменяет прежнего Telegram-бота.

Технически: один Flask-сервер отдаёт статическую страницу (`static/`)
и простой JSON API (`/api/profiles`) поверх SQLite. "Владение" своей
анкетой (чтобы отметить "нашёл команду" или удалить) подтверждается
токеном, который браузер сохраняет у себя (localStorage) — без токена
изменить чужую анкету нельзя, но это работает только на том же
устройстве/браузере, где анкета создавалась.

## 1. Запуск локально (проверить перед деплоем)

```bash
cd team_finder_site
python -m venv venv
venv\Scripts\activate        # Windows PowerShell; на Mac/Linux: source venv/bin/activate
pip install -r requirements.txt
python app.py
```

Откроется на `http://localhost:5000` — зайди туда в браузере.

## 2. Деплой на Railway (как и с ботом)

1. Залей содержимое этой папки в тот же GitHub-репозиторий (можно
   заменить старые файлы бота этими — сайт его полностью заменяет)
   или создай новый репозиторий — как удобнее
2. В Railway: New Project → Deploy from GitHub repo → выбери репозиторий
3. **Сразу подключи постоянный диск**, чтобы не потерять анкеты при
   следующем обновлении кода (это тот же урок, что был с ботом):
   - Command Palette (Ctrl/Cmd+K) → Create Volume → Mount Path: `/data`
   - Variables → New Variable → `DB_DIR` = `/data`
4. Railway сам подхватит `Procfile` (`web: python app.py`) и задеплоит
5. Открой публичный домен сервиса (Railway выдаёт его сам в разделе
   Settings → Networking → Generate Domain, если ещё не включён) —
   это и есть ссылка на сайт, её можно скидывать всем

## 3. Посмотреть базу данных самому

Аналог `/export` у бота — эндпоинт с секретным ключом:

1. В Railway: Variables → добавь `ADMIN_KEY`, придумай длинную
   случайную строку (например, сгенерируй на randomkeygen.com)
2. Открой в браузере: `https://твой-домен.up.railway.app/api/export?key=ТВОЙ_КЛЮЧ`
3. Скачается файл `site.db` — открывай в **DB Browser for SQLite**
   (sqlitebrowser.org) или расширением **SQLite Viewer** в VS Code

Никому не показывай `ADMIN_KEY` и не пости скриншоты со значением в
адресной строке — с этим ключом кто угодно сможет скачать всю базу.

## 4. Ограничения текущей версии (осознанный выбор для MVP)

- Без аккаунтов: владение анкетой держится на токене в браузере. Если
  человек зайдёт с другого устройства или почистит данные браузера —
  он не сможет отредактировать/удалить старую анкету оттуда (создать
  новую можно всегда)
- Нет постраничной загрузки (пагинации) — при очень большом числе
  анкет страница будет длинной. Для масштаба одного университета это
  не проблема
- Поиск — простое совпадение по подстроке (как `/find` у бота), не
  полнотекстовый поиск

## 5. Как обновлять дальше

Так же, как с ботом — заменяешь файлы на GitHub (Add file → Upload
files → перетащить с заменой), Railway сам передеплоит. Данные в базе
не теряются при обычном редеплое (только при пересоздании сервиса —
тогда сначала `/api/export`, потом восстановление вручную через
DB Browser, залив содержимое обратно, либо попроси всех просто
заполнить анкету заново, если их немного).
